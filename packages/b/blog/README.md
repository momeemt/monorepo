# blog.momee.mt

Astro blog with MDX posts, Shiki code blocks, KaTeX math, and a card layout
based on the previous `blog.momee.mt`.

## Commands

```sh
npm run dev
npm run build
npm run preview
```

## Posts

Add posts under `src/content/posts/` as `.mdx` files with this frontmatter:

```md
---
title: Post title
category: Tech
description: Optional summary.
pubDate: 2026/05/28
tags:
  - Astro
thumbnail: smoking-girl
---
```
